- **Code name:** ASTRAEUS
- **Full name:** Autonomous Scientific Tool for Research, Analysis, and
  Experimental Understanding of Space
- **Author:** Zubayer Hasan Shaad
- **Code site:** https://github.com/zabdax/project-astraeus
- **License:** MIT
- **Description:** Physics-first computational astrophysics platform for
  exoplanet transit modeling: blind transit search with Box Least
  Squares cross-validated by Transit Least Squares, U/V-shape and
  secondary-eclipse vetting, transit-timing-variation analysis, MCMC
  parameter retrieval with convergence gates, and a FastAPI + Next.js
  interface with full run provenance. No black-box ML shortcuts; every
  gate is fail-closed and every result carries its capability snapshot.
